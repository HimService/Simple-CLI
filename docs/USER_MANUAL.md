# 🚀 Simple CLI (SPC) 官方使用手冊

歡迎使用 **Simple CLI (SPC)** — 您的終端機 AI 專案助手。這份手冊將引導您從基礎安裝到進階專案自動化，讓 AI 成為您開發流程中的核心動力。

---

## 📦 1. 安裝與全域設置

### 快速全域連結
1.  在本專案根目錄下執行 `npm install`。
2.  執行 `npm run build` 進行編譯。
3.  啟動 `spc config`（或手動執行 `npm link`）。
4.  開啟 **「全域啟動指令 (spc)」** 功能。

現在，您可以在電腦的 **任何位置** 直接輸入 `spc` 啟動工具！

---

## 🎯 2. 二種啟動模式

### 🔹 通用助理模式 (`spc`)
-   **特性**：AI 不會感應您的檔案路徑。
-   **用途**：一般的問答、代碼片段生成、不希望 AI 觸碰專案時。
-   **UI 表現**：極簡介面，不顯示路徑。

### 🔹 專案感應模式 (`spc -f`)
-   **特性**：AI 會獲得「專案管理員」權限，並精確知道目前所在的工作目錄。
-   **自動感應**：若根目錄有 `SPC.md`，AI 將自動遵守相關規範。
-   **用途**：專案開發、錯誤修補、自動化重構、遵守特定代碼風格。

---

## 🧠 3. 專案自定義規則 (SPC.md)

這是讓 AI 真正「懂」您專案的神祕配方。只需在專案根目錄建立一個 `SPC.md` 文件。

### 範例：React 專案規則
```markdown
# 專案規範
1. 所有組件必須使用 TypeScript (TSX)。
2. 組件請統一放在 `/src/components` 目錄下。
3. 使用 CSS Modules 進行樣式管理。
4. 命名規則：組件使用 PascalCase，變數使用 camelCase。
5. 在執行指令前，請先確認是否會破壞現有的測試環境。
```

當您使用 `spc -f` 啟動時，AI 會主動讀取這些規則並在執行任務時嚴格遵守，無需您每次重複提醒。

---

## 🛡️ 4. 安全與權限管理

### 三層安全防護
1.  **手動確認模式 (預設)**：執行 `runCommand` 等敏感功能前，AI 會停下來詢問您的意見。
2.  **自動執行模式 (風險)**：AI 可以在無需確認的情況下自主完成任務（適用於批次改檔或重複性任務）。
3.  **敏感工具標記**：即使在自動模式下，某些被開發者標記為 `isSensitive` 的擴充工具依然會觸發詢問。

這些設定皆可在 `spc config` 的 **「🛡️ 安全性與權限管理」** 中調整。

## 🔌 5. 開發者：如何撰寫擴充工具？

1.  在 `plugins/` 目錄下建立 `.js` 檔案。
2.  導出一個符合規定的 `ToolDefinition` 對象。
3.  **詳細教學** 請參閱 [PLUGINS_GUIDE.md](./PLUGINS_GUIDE.md)。

## 💡 常見問題 (FAQ)

-   **Q: 為什麼 `spc -f` 沒抓到我的路徑？**
    -   請確保您已經編譯最新代碼，並使用 `spc -f` (大寫 F 或小寫) 的正確旗標。
-   **Q: 如何更換 AI 模型？**
    -   進入 `spc config` -> `🔌 模型提供商設定` 即可快速切換 OpenAI、Gemini 或本地的 LM Studio。
